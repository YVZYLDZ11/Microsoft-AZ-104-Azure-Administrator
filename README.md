# Microsoft-AZ-104-Azure-Administrator
I'm currently preparing for the Microsoft AZ-104: Microsoft Certified: Azure Administrator Associate certification exam.
I already have a solid theoretical understanding of Azure administrator concepts, and I'm now focusing on reinforcing that knowledge through hands-on practice.

For each lab I complete, I export the deployment as an ARM template directly from the Azure portal.
This allows me to apply the principles of Infrastructure as Code (IaC) and understand Azure networking in a much deeper and more practical way.

As I progress through the modules, I will keep uploading my completed labs and ARM templates to this repository.
This not only helps me track my progress, but also serves as a reference for others preparing for the AZ-104 exam.
