## 📖 About This Repository
This repository documents my journey towards the **Microsoft Certified: Azure Administrator Associate (AZ-104)** certification. It contains hands-on labs, PowerShell/CLI scripts, ARM templates, and study notes created during my preparation.

## 🎯 Learning Objectives & Lab Progress
Below is the list of hands-on labs covering the official exam objectives.

### 🆔 Module 1: Identity and Governance
- [ ] Manage Azure Active Directory (Entra ID) Users & Groups
- [ ] Configure Subscription Policies & RBAC
- [ ] Implement Management Groups

### 💾 Module 2: Implement and Manage Storage
- [ ] Create and Configure Storage Accounts
- [ ] Manage Blob Storage & Lifecycle Management
- [ ] Configure Azure Files & File Sync

### 💻 Module 3: Deploy and Manage Azure Compute Resources
- [ ] Deploy Virtual Machines (Windows/Linux)
- [ ] Configure VM Availability (Sets & Zones)
- [ ] Create and Manage App Services
- [ ] Container Solutions (ACI & AKS basics)

### 🌐 Module 4: Configure and Manage Virtual Networking
- [ ] Implement Virtual Networks (VNet) & Subnets
- [ ] Configure Network Security Groups (NSGs) & ASGs
- [ ] VNet Peering & VPN Gateway Connectivity
- [ ] Configure Azure DNS & Load Balancers

### 🛡️ Module 5: Monitor and Back Up Azure Resources
- [ ] Monitor Resources with Azure Monitor & Alerts
- [ ] Implement Backup and Recovery (Recovery Services Vault)
- [ ] Analyze Logs with Log Analytics
